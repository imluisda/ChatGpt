# Mini Kanban App

Esta es una aplicación web sencilla para gestionar tareas al estilo Kanban. Permite iniciar sesión con un usuario predefinido y mover tareas entre los estados `Por hacer`, `En progreso` y `Hecho`.

## Uso

1. Instala las dependencias:
   ```bash
   npm install
   ```
2. Inicia el servidor:
   ```bash
   node server.js
   ```
3. Abre `http://localhost:3000` en tu navegador.
4. Inicia sesión con:
   - **Usuario:** `admin`
   - **Contraseña:** `password`

Al hacer clic sobre una tarea, ésta avanza al siguiente estado.
